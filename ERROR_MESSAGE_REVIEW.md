# Initial errors and safe recovery

Observed installed help/version are local, metadata dispatch does not consume authority. Unknown leading flags/missing executable/invalid trusted path correctly reject12. Watch redirected/dumb rejects12 with a safe JSON suggestion. Broker unavailable/status/history permission errors retain stable machine codes and do not elevate. Read-only JSON is preferred for automation.

E1 LOW: unsupported watch explains restriction but no plain human option; add explicit plain mode and precise TTY/TERM recovery wording, never ANSI into pipes.

E2 LOW: requester broker errors can expose raw [Errno2]/connection text as the sole next-action guidance. Add bounded static human guidance after the existing prefix/code: check operator status; do not resubmit an uncertain operation. Do not infer no approval console from broker health, start/restart a service, leak request arguments, or change error categorization.

Expiry/denial/epoch/unknown outcomes already have distinct stable codes; do not prettify them into retry instructions. BUSY/UNKNOWN preflight remains observational, not a restart authorization.
