# Historical Mayi records

These files preserve earlier experiments and qualification evidence. They are not current feature guides and must not be used to infer that a prototype, protocol, or unfinished executor is part of Mayi 0.4.1.

- [`PRIVILEGED_BOUNDARY_QUALIFICATION.md`](PRIVILEGED_BOUNDARY_QUALIFICATION.md) — superseded prototype qualification; it does not qualify the current generic executor.
- [`filesystem/FILESYSTEM_EXECUTOR_REMEDIATION.md`](filesystem/FILESYSTEM_EXECUTOR_REMEDIATION.md) — detailed incomplete filesystem-core qualification snapshot.
- [`filesystem/OPENAT2_HARDENING.md`](filesystem/OPENAT2_HARDENING.md) — filesystem path-resolution research.
- [`filesystem/RACE_HARDENING.md`](filesystem/RACE_HARDENING.md) — filesystem race-hardening research.

The current filesystem feature gate is summarized in [`../FILESYSTEM_EXECUTOR_STATUS.md`](../FILESYSTEM_EXECUTOR_STATUS.md). Current supported behavior starts at the repository [README](../../README.md); current architecture/security are in the root [`ARCHITECTURE.md`](../../ARCHITECTURE.md) and [`SECURITY_BOUNDARY.md`](../../SECURITY_BOUNDARY.md).
